## Especificações Técnicas
Para rodar essa merda sem lag, você vai precisar de:
* **OS:** Windows 7/10/11 (64 bits)
* **Espaço:** 5 GB disponíveis em disco
* **Engine:** Psych Engine (Modificada por mim)
